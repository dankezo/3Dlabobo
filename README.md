# 3D Lab

Interactive 3D machine simulators you can take apart — one HTML page per lab, built with Three.js.

## Labs

- **Lab 01 — Cat Jelly Press**: https://dankezo.github.io/cat-jelly/press.html (repo: [dankezo/cat-jelly](https://github.com/dankezo/cat-jelly))
- **Lab 02 — Mecha Cat Teardown**: this repo, served at https://dankezo.github.io/3Dlabobo/ — a procedural Three.js mecha cat driven by one solver (crank phase → trot gait, 2-bone IK legs). Take it apart subsystem by subsystem (head, energy core, chassis, tail, four legs), with live charts, X-ray / exploded views, and a self-driving tour. Also at `labs/lab-02-mecha-cat-teardown/index.html`.

## Reproducing a lab

Every lab ships with full documentation, a master prompt, and a required tools / CLI / skills list inside the lab page and in its `labs/<lab>/` folder.
